# GridCompare

> Sizing up the gap.

---

## About GridCompare

Easily compare your favorite Formula 1 drivers and constructors side-by-side using intuitive, interactive visualizations.

* **Head-to-Head Statistics:** Compare career and season performance, including total race wins, race entries, fastest laps, and current season points.
* **Multi-Entity Timeline Analysis:** Track and compare up to 5 drivers or constructors simultaneously across historical timelines to spot performance trends and season trajectories.
* **Clean Data Visualizations:** View key metrics transformed into easy-to-read charts and graphs for quick analysis.

---

## Tech Stack

- **Frontend:** React, HTML5, CSS3
- **Data Visualization:** Chart.js (react-chartjs-2)
- **Data Source / API:** Jolpica F1 API
- **Architecture:** Client-side Single Page Application (SPA), RESTful API integration, and modular component-driven design.

---

## Project Structure

```text
public/                 # Static assets and root HTML template
src/                    # Core application source code
Assets/                 # Static media (constructors, drivers, images)
Components/             # Reusable UI elements and chart components
Data/                   # Local datasets, mock data, and API helper functions
Documentation/          # Project documentation 
Pages/                  # Primary page views and screen layouts
App.js                  # Main application component and route handling
index.js                # React DOM entry point
```

## Installation & Local Setup

### 1. Prerequisites

Ensure you have the following installed locally:

* **Runtime Environment:** [Node.js](https://nodejs.org/) 
* **Package Manager:** [npm](https://www.npmjs.com/) (bundled with Node)
* **Version Control:** [Git](https://git-scm.com/)
* **Web Browser:** Modern browser (Chrome)
